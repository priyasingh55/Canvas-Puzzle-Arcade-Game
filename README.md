# 🎮 Puzzle Arcade Game Hub

A rich multi-game arcade collection built with **React**, **Vite**, **TypeScript**, and HTML5 **Canvas**.

## 🕹️ Included Games

1. **Word Search** – Classic word finding puzzle
2. **Water Sort** – Color sorting puzzle with tubes
3. **Word Scramble** – Fast-paced anagram and word unscramble
4. **Snake** – Classic arcade snake game
5. **Ludo** – Turn-based board game
6. **Speed Typer** – Typing speed challenge
7. **Bow Brawl** – Archer physics combat
8. **Memory Match** – Card flipping memory game
9. **Four in a Row** – Strategic Connect-4 style game
10. **Make Ten** – Number addition puzzle
11. **Number Match** – Match pairs of numbers
12. **Sum Chain** – Mathematical pathfinder
13. **Merge Double** – 2048-style number merging
14. **Tile Slide** – 15-puzzle sliding blocks
15. **Glow Grid** – Light-up grid logic puzzle
16. **Pipe Garden** – Connect pipes to water plants
17. **Quiz Builder** – Interactive quiz trivia
18. **Critter Keeper** – Virtual pet simulator
19. **Maze Maker** – Procedural maze navigation
20. **Bubble Sort** – Physics bubble matching
21. **Bubble Burst** – Match-3 popping action
22. **Hoop Pop** – Basketball physics shooting
23. **Sling Squad** – Slingshot trajectory puzzle
24. **Cannon Drop** – Cannon trajectory target game
25. **Hill Rider** – 2D physics vehicle hill climbing
26. **Planet Merge** – Suika-style merging physics puzzle

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or pnpm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/priyasingh55/Canvas-Puzzle-Arcade-Game.git

# Navigate to project directory
cd puzzle-arcade-game

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Build for Production
```bash
npm run build
```

## 🛠️ Tech Stack
- **Framework:** React 19
- **Build Tool:** Vite
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Physics:** Planck.js
- **Graphics:** HTML5 Canvas API
